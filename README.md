# Kajal Gayakwad — Portfolio

A responsive React + TypeScript portfolio built with Vite and custom CSS. It is ready to deploy to Vercel.

## Run locally

1. Install Node.js (LTS).
2. Extract this ZIP and open the project folder in VS Code.
3. In the terminal, run:

   ```bash
   npm install
   npm run dev
   ```

4. Open the local URL printed by Vite (usually http://localhost:5173).

## Build

```bash
npm run build
```

Vite outputs the production site to `dist/`.

## Deploy to Vercel for free

1. Create or sign in to GitHub: https://github.com/
2. Create a new repository, for example `kajal-portfolio`.
3. Upload the contents of this project folder to that repository (the `package.json` must be at the repository root).
4. Sign in to https://vercel.com/ using GitHub.
5. Choose **Add New → Project**, import `kajal-portfolio`, and deploy.
6. Vercel should detect Vite automatically. Build command: `npm run build`; output directory: `dist`.
7. After deployment, Vercel gives you a public `*.vercel.app` URL.
